## 🇬🇧 English

### 📖 About

**Sajad Store** is a frontend practice project built to apply and demonstrate JavaScript concepts in a real-world e-commerce scenario.

The project includes product fetching from an API, product search, shopping cart management, LocalStorage persistence, quantity control, price calculation, checkout, and order confirmation.

### ✨ Features

* 🔌 Fetch products from an API
* 🔍 Search products
* 🛒 Add products to cart
* 🚫 Prevent duplicate products in cart
* 💾 Save cart data using LocalStorage
* 🔄 Restore cart data after page refresh
* ➕ Increase product quantity
* ➖ Decrease product quantity
* 🗑️ Remove products when quantity reaches zero
* 💰 Calculate individual product prices
* 🧾 Calculate total cart price
* 📦 Checkout and Order Summary
* ✅ Confirm orders
* 🧹 Clear cart after order confirmation
* 📱 Responsive frontend interface

### 🛠️ Technologies

* HTML5
* CSS3
* JavaScript (Vanilla JS)
* Fetch API
* LocalStorage
* ES Modules

### 🚀 How to Run

1. Clone or download the repository.
2. Open the project in **VS Code**.
3. Run the project using a local development server such as **Live Server**.
4. Open `index.html` in your browser.

> Because the project uses JavaScript modules and API requests, running it through a local server is recommended.
